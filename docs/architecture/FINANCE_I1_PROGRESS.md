## 4. Environment quirks

- Git Bash on Windows: every command ends with a spurious `exit 1` (`claude-XXXX-cwd`). Judge by output; append `; echo EXIT=$?`. Heredocs with quotes sometimes break in Bash; prefer the Write/Edit tools for files.
- ssh: `ssh -F C:/Users/D064974/.ssh/config episteck-node1` (Nuremberg, user `episteck`, passwordless sudo) or `episteck-home` (Ashburn, user `frappe`).
- Rootless podman: start remote commands with `cd /`; use `sudo -n -u svc-x env XDG_RUNTIME_DIR=/run/user/$(id -u svc-x) …`; `systemctl --user` also needs `DBUS_SESSION_BUS_ADDRESS=unix:path=/run/user/$UID/bus`.
- Isolated tests (from `services/finance`): `uv run --no-project --python 3.13 --with "fastapi>=0.140" --with uvicorn --with "pydantic>=2" --with httpx --with fastmcp==4.0.3 --with "pyjwt[crypto]" --with pytest python -m pytest tests -q ; echo EXIT=$?`. Deploy artifacts: `uv run --no-project --python 3.13 --with pytest python -m pytest deploy/finance/tests -q` from the repo root. Home and BFF have their own commands in their plans.
- Linux test run (POSIX tests): `wsl -d Ubuntu -- bash -lc 'rm -rf /tmp/fin && mkdir -p /tmp/fin && cp -r <worktree>/services <worktree>/deploy /tmp/fin/ && cd /tmp/fin/services/finance && uv run --no-project --python 3.13 --with "fastapi>=0.140" --with uvicorn --with "pydantic>=2" --with httpx --with fastmcp==4.0.3 --with "pyjwt[crypto]" --with pytest python -m pytest tests -q'` (WSL paths are `/mnt/c/AIProjects/...`; for `deploy/finance/tests` also copy `docs/architecture/DEPLOYMENT.md` and `docs/runbooks/*.md` under `/tmp/fin/docs/`).
- `git push` of many branches at once can be rejected with a transient `remote rejected (failure)`; check with `git fetch` and push the stragglers one by one.
- Always `git fetch` and work from `origin/main`; the primary checkout's `main` is far behind. New work goes in a new worktree under `.worktrees/`.
