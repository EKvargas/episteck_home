# Episteck Home

Versioned Frappe app source for the small, privacy-first EPISTECK HOME core.

This package is deliberately **not installed** on any site by this commit. Its
first executable scope is a synthetic Care Journey/Pregnancy Journey pilot and
the small Nutrition Profile/Intake core. It contains neither clinical records,
device credentials, raw wearable payloads, AI endpoints nor external service
connectors.

The future Device Gateway owns raw health-source data outside Frappe. Home may
consume only explicitly authorised summaries or references.
